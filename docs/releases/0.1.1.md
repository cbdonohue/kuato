# Kuato 0.1.1

**30 August 2026**

Follow-up to 0.1.0 the same day: one new coach action, a mock-draft roster fix, and the repo / docs / CI work that makes this a real GitHub project. Rankings still run with no LLM key. Auction and dynasty stay out of scope.

## Highlights

- **Injury analysis** — optional coach action that maps Sleeper injury flags on your roster and the remaining board
- **Mock drafts fill Your roster** — when Sleeper omits `roster_id`, picks are attributed by `draft_slot`, so need scoring and the roster panel match the room
- **Open in Codespaces** — Node 20 devcontainer installs, writes `.env.local`, starts the app, and forwards port 3000. Login works through the `*.app.github.dev` forwarded host
- **Project files** — MIT license, contributing guide, code of conduct, security policy, issue forms, PR template, Dependabot, architecture notes, and deploy notes

## Coach

- New action: Injury analysis
- `AI_MODEL` overrides the default id (`gpt-4o-mini` or `claude-3-5-haiku-latest`). Documented in `.env.example` and honored in `src/lib/llm.ts`

## Live room

- README lists the clock, news strip, top-5 reasons, remaining-board filters, scoring inputs, and every coach action
- README walkthrough is an animated WebP (GitHub will not play a repo-hosted `<video>`)
- Helmet logo restored at the top of the README

## Docs and repo

- [`docs/architecture.md`](../architecture.md) — how a live room is assembled
- [`docs/deploy.md`](../deploy.md) — Vercel or any Node 20 host; cache writes stay best-effort on a read-only filesystem
- Cursor rules under `.cursor/rules`
- Unused Next.js starter SVGs removed from `public/`

## CI and local quality

- Lint and TypeScript (`next typegen && tsc --noEmit`) run next to the 80% coverage job
- ESLint fixes so that lint step stays green (`prefer-const`, unused import, React purity on AI triggers, localStorage hydration)

## Upgrade notes

If you already have a Codespace, rebuild it so it picks up `.devcontainer`. Set `SITE_PASSWORD`. Add `OPENAI_API_KEY` or `ANTHROPIC_API_KEY` only if you want the coach; set `AI_MODEL` only to override the default.
